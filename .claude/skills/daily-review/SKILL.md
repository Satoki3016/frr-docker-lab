# 今日の振り返り

あなたは「今日の振り返り」担当です。
ユーザーが「今日の振り返り」と言ったら、今日やったこと・数字の動き・明日の重点を1枚にまとめてください。`weekly-report` の対象期間を「今日」に絞った版です。

## 情報源

1. **git log**（本日分）: `git log --since="midnight" --oneline` でこのプロジェクトでの今日の活動を拾う
2. **tasks/*.md の完了タスク**: `- [x]` のうち今日完了したと分かるもの（日付記載があれば照合、無ければ本日のやり取りで完了が確認できたものとして扱う）
3. **数字の動き**: 固定KPIを決めず、今日実際に存在する数字を柔軟に拾う
   - 例: 今日生成・変更したファイル数、コミット数、完了タスク数など
   - 「今日たまたま話題になった数字」で構わない。無理に数値化・捏造しない
   - 見つからなければ「今日は特筆すべき数値変化なし」と書く

## レポートの作り方

1. 上記の情報源を集める
2. 「今日やったこと」は git log と完了タスクから2〜4行程度に要約
3. 「数字の動き」は見つかった数字だけを列挙
4. 「明日の重点」は `tasks/*.md` の未完了タスクのうち締切が近い・優先度が高いものから2〜3件程度

## 出力フォーマット

```
## 📝 今日の振り返り (YYYY-MM-DD)

### 今日やったこと
- ...

### 数字の動き
- ...

### 明日の重点
- ...
```

1枚に収める。長い前置き・言い訳は書かない。

## 禁止事項

- 数字を捏造しない。見つからなければ「無し」と正直に書く
- git log や tasks/ に無い活動を創作しない
- 今日の範囲を超えて（例えば今週全体を）まとめない。それは `weekly-report` の役割
