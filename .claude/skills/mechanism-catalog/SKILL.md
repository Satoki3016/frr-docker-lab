# 仕組み名鑑

あなたは「仕組み名鑑」担当です。
ユーザーが自作の仕組み・テンプレの一覧を見たい・更新したいと言ったら、以下の手順で `仕組み名鑑.md`（プロジェクトルート）を更新してください。

## スキャン対象

このプロジェクト（`frr-docker-lab-main2`）内の以下を対象にする。キャッシュせず、呼ばれるたびに毎回スキャンし直す（新規追加分を取りこぼさないため）。

1. **`.claude/skills/*/SKILL.md`**（最優先の索引対象）— 全て読み、frontmatterの `name` と `description` を抽出する
2. **その他のテンプレ・仕組み候補** — プロジェクト直下・サブディレクトリのうち、ファイル名やヘッダーから明らかに「手順書」「テンプレ」「仕組み」と分かるもの
   （例: ファイル名に「テンプレ」「手順書」「_template」等を含む、あるいは冒頭コメントで自身を定型作業の再現装置と説明しているファイル）

## 索引化の手順

1. `.claude/skills/*/SKILL.md` を全て読み込む
2. 上記2.の候補を探す（見つからなければ「その他のテンプレ・仕組み」欄は「無し」とする）
3. `仕組み名鑑.md` に以下の形式で書き出す（既存ファイルがあれば全面上書きで最新化する）

## 出力フォーマット（`仕組み名鑑.md` の中身）

```markdown
# 仕組み名鑑

最終更新: YYYY-MM-DD

## Claude Code スキル (.claude/skills/)

| 名前 | 呼び出し方 | 何をするか |
|---|---|---|
| <name> | `/<name>` | <descriptionの要約1行> |

## その他のテンプレ・仕組み

| ファイル | 何をするか |
|---|---|
| <path> | <1行説明> |
```

候補が無い場合は該当セクションに「現時点では無し」と書く。

## 禁止事項

- 実在しない仕組みを創作しない。スキャンして見つかったものだけを載せる
- 古い版を手作業でマージしない。毎回フルスキャンして全面上書きする
