# English figures (for international-conference presentation)

English-labelled versions of the DiffServ-TE (HTB Strict Priority + WRR)
comparison figures. Styled for slides/posters: clean sans-serif, larger fonts,
300 dpi PNG + vector PDF.

Generated by `plot_sp_ablation_en.py` from the raw logs under `../../frr/`
(same data as the Japanese version in `../ja/`).

## Experimental conditions (all figures)

- All environments unified at **CR bandwidth = 9 Gbps, TX = 8 Gbps/class**
  (send and link conditions matched to remove confounds).
- Comparison variables: **SP mode** (Strict Priority enabled/disabled) and
  **environment** (veth simulation vs C2 hardware testbed).
- "SP disabled" = `PRIO_HI=1`: AF41 dropped to the same priority as AF42/AF43,
  leaving only WRR (quantum ratio 4:2:1).

## Figure list

| File | Description |

## Key messages

1. **Strict Priority protects AF41**: enabling SP keeps AF41 loss near zero
   (~0.001–0.01%); disabling it makes AF41 a plain WRR participant with 34% loss.
   Identical in simulation and hardware -> the design rule is environment-independent.
2. **SP trades throughput and delay for AF41**: with SP, AF41 gets both the most
   bandwidth (8 G) and the lowest delay; AF42/AF43 pay the cost.
3. **OSPF-SR auto-reroute** cuts the outage from ~17 s (no reroute) to ~1–2 s,
   consistently across environments.
