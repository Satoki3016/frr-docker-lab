# tasks/ の使い方

`morning-directive` スキル（「今日なにやる？」）と `weekly-report` スキル（「今週の振り返り」）が読むタスクリースト置き場です。

1ファイル = 1部門。ファイル名は部門名（例: `研究.md`、`実験.md`、`執筆.md`）。

## フォーマット

```markdown
# <部門名>

- [ ] タスク内容 (締切: YYYY-MM-DD) [優先度: 高/中/低]
- [x] 完了したタスク (締切: YYYY-MM-DD)
```

- `- [ ]` = 未完了、`- [x]` = 完了
- 締切・優先度は無くてもよい（無い場合は「確認したいこと」に回される）
- 完了タスクは週次レポートで拾われるので、消さずに残しておくと振り返りに使える

## 新しい部門を増やすには

`tasks/新しい部門名.md` を上記フォーマットで作るだけです。特別な登録作業は不要です。
